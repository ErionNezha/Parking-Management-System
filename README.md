# Parking Management System (C)

Sistem menaxhimi parkimi në C — regjistrim hyrjesh/daljesh automjetesh me llogaritje kohe dhe tarifash.

`C`

## 🚀 Live Demo
Hape **`index.html`** në browser — demo-ja ekzekutohet direkt, pa instalime.
Nëse repo është publikuar me GitHub Pages: `https://erionnezha.github.io/Parking-Management-System/`

## 📝 Kodi Burim
Kodi i plotë është në dosjen [`original/`](original/) dhe shfaqet krahas demo-s live në `index.html`.

## ▶️ Ekzekutimi origjinal
Kompilo me `gcc Parking.c -o parking` (Windows) dhe ekzekuto.
